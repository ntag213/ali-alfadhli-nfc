# علي الفاضلي — بطاقة NFC (Bio-Link)

صفحة واحدة بتصميم تطبيق iOS: عروض منظومات الرابعة، الدوريات، الخدمات، منشورات فيسبوك، طرق الدفع مع زر نسخ، والموقع.
على الهاتف تظهر داخل إطار iPhone مع شريط تنقل سفلي، وعلى الكمبيوتر والآيباد تتحول إلى لوحة عريضة بثلاثة أعمدة.

## الملفات
| الملف | المحتوى |
|---|---|
| `index.html` | هيكل الصفحة وأيقونات SVG وربط الملفات |
| `style.css` | كل التنسيقات: الإطار، الشريط السفلي، Glassmorphism، لوحة سطح المكتب، قسم الـ 3D |
| `script.js` | التنقل بين الأقسام، النسخ، المنشورات، والعرض ثلاثي الأبعاد (Three.js) |

لا يوجد بناء ولا تثبيت. المكتبة الوحيدة الخارجية هي Three.js وتُحمَّل تلقائياً من cdnjs ثم jsDelivr ثم unpkg، وإن تعذّر ذلك يظهر عرض CSS 3D مبسّط.

## التشغيل محلياً
افتح `index.html` في المتصفح، أو من VS Code بإضافة Live Server، أو:
```bash
python3 -m http.server 8000   # ثم افتح http://localhost:8000
```

## النشر على GitHub Pages
1. ارفع الملفات الثلاثة (و`README.md`) إلى مستودع جديد.
2. من `Settings → Pages` اختر `Deploy from a branch` ثم `main` و`/ (root)`.
3. انسخ الرابط الناتج وسجّله على شريحة NFC.

## أين أعدّل؟
- **الأرقام والروابط:** في `index.html` (واتساب `wa.me/9647707235990`، الاتصال، رقما الدفع في `data-num`).
- **الصورة الشخصية:** ضع ملف الصورة بجانب `index.html` واكتب اسمه في `src` داخل `<img id="avatar">`.
- **المنشورات:** نصوص وتواريخ كروت الفيسبوك داخل `index.html`، ولعرض صورة ضع رابطها في `data-img`.
- **أسماء ووصف قطع الـ 3D والعبارات:** الكائن `META` في بداية قسم "3D products" داخل `script.js`.
- **طول التفكيك مع السكرول:** `.pwrap { height: 300vh }` في `style.css`.
